# Klyrune Releases

Официальный публичный репозиторий релизов **Klyrune** — настольного приложения для Windows 10/11 (x64), помогающего безопасно анализировать файловую систему и осознанно освобождать место на диске.

## Основные принципы Klyrune

- **Никакого автоматического удаления:** каждое действие выполняется только после явного подтверждения пользователя.
- **Прозрачность и объяснимость:** для каждого кандидата отображаются причина рекомендации, путь, размер, категория и уровень риска.
- **Защита данных:** консервативная защита системных каталогов Windows и пользовательских данных.
- **Карантин и восстановление:** перемещение в карантин там, где это технически возможно, и проверка конфликтов при восстановлении.
- **Минимальные привилегии:** обычное сканирование не требует прав администратора.

## Загрузка и проверка целостности

Готовые сборки публикуются исключительно в разделе **[Releases](https://github.com/Klyrune/Klyrune-Releases/releases)** в виде архивов формата `Klyrune-Windows-x64-vX.Y.Z.zip` вместе с файлом контрольных сумм `SHA256SUMS.txt`.

### Проверка SHA-256 в PowerShell

```powershell
Get-FileHash .\Klyrune-Windows-x64-vX.Y.Z.zip -Algorithm SHA256
```

Сравните полученный хеш со строкой из файла `SHA256SUMS.txt`, приложенного к тому же релизу. Не запускайте архивы, если контрольная сумма не совпадает.
